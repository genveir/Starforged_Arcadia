# Campaign Clocks

Tracked values that increment between sessions.

## How to use

When something in the campaign is progressing outside of the character's control, a clock can be added. Pick a name and add a short description. Pick a number of boxes for its progress track when creating it. If there is a matter of chance on whether or not this clock advances each session, include a percentage chance that it will increase.

When ending a session check against any active campaign clocks. If progress is uncertain, roll d100 and determine if the clock progresses. Mark 1 box on each clock that progresses.

When a clock is full, it's effects fire in the next session. Then remove the clock.

If a clock becomes obsolete because of events in play, remove it.
