## Move Glossary

**"Companion"** — An NPC asset.

**"In Control" / "In a Bad Spot"** — In control = proactive moves (Gain Ground, Strike). In a bad spot = reactive moves (React Under Fire, Clash). When a move doesn't specify: SH = in control; WH or M = in a bad spot.

**"Mark Progress"** — Fill boxes or ticks per the challenge rank. If a move and an asset ability both reward progress for the same action, mark progress twice.

**"Matches"** — Both challenge dice show the same number. Follow move instructions if given. Otherwise: SH match = twist or new opportunity; M match = unexpected worsening.

**"Progress Move (PM)"** — Resolves a goal or challenge. Progress score = fully filled boxes only (four ticks = one box). Roll challenge dice and compare to progress score — no stat, no adds, no momentum burn, negative momentum has no effect.

**"SH / WH / M"** — Strong hit / Weak hit / Miss. SH = action score beats both challenge dice. WH = beats one. M = beats neither. Ties go to the challenge dice.

**"PtP"** — Pay the Price.

**"+stat"** — Free choice of stat. Pick the one that fits your fictional approach. See stat reference for guidance on what each stat covers.
| Stat | Covers |
|---|---|
| Edge | Speed, agility, precision, pursuit, fleeing, precision attack |
| Heart | Resolve, command, charm, courage, sociability, loyalty, bravery |
| Iron | Strength, endurance, aggression, force, powerful strikes |
| Shadow | Deception, stealth, trickery, misdirection, ambush |
| Wits | Expertise, focus, observation, insight, analysis, planning |

**"+(X)mom / -(X)mom"** — Increase or decrease the momentum meter by X.
